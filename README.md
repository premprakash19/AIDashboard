# L2 Support Ticket Insights — source

Source for the dashboard in `..\index.html`. You only need this folder to change the dashboard
itself (layout, logic, name-removal rules, built-in data). Day-to-day data refreshes are done
on the page with **Add data files** and **Download updated dashboard**.

## Sample data

The built-in data is **fictitious**: about 1,500 generated tickets for "Contoso Workplace", a made-up
employee self-service portal (leave, expenses, timesheets, payslips). Ticket numbers, servers and teams
are invented, and the tickets contain no people, emails or customer details. `gen-sample-data.js`
creates it with a fixed seed:

```
node gen-sample-data.js
node apply-redact.js
node build.js --no-login
```

`auth.private.json` holds a demo sign-in (`demo` / `contoso-demo`) used when you build without `--no-login`.

**When you use your own data, keep this folder private.** `data\baseline.json` then holds the
original ticket text, `redact-lists.js` the customer and people names that are removed, and
`auth.private.json` the dashboard sign-in. Only `..\index.html` goes on the server.

## Sign-in and encryption

The built-in data in `index.html` is gzipped and then encrypted with AES-256-GCM. The key is derived
with PBKDF2-SHA256 (310,000 rounds, random salt) from the user ID and password in `auth.private.json`.
The page never contains the user ID, the password or any readable ticket. A wrong sign-in simply fails
to decrypt. User IDs are not case-sensitive. Passwords are.

- Data kept in the browser between visits is encrypted the same way, one slot per user ID.
- **Start fresh with these files** asks who may open the fresh dashboard: your own user ID and
  password, the current sign-in, or no sign-in. **Download updated dashboard** then saves a copy
  protected with that choice.
- **Sign out** locks the page again.
- An encrypted page must be opened from an `https://` address or as a local file. Browsers block
  the decryption functions on plain `http://`.

To change the built-in sign-in, edit `auth.private.json` (or set `L2_USER` and `L2_PASS`) and rebuild.
`node build.js --no-login` builds a page without sign-in.

## Rebuild

Needs Node.js (any recent version; no packages to install). From this folder:

```
node build.js
```

This writes:
- `..\index.html` — the static website file (replaces the current one)
- `dist\l2-support-insights.html` — the version published as a Claude artifact

The build stops with an error if the page script has a syntax error, and it prints
`listed names present in page: none` when no name from `redact-lists.js` ended up in the page.
It also stops if the sign-in or any readable ticket is found in the page.

## Change which names are removed

1. Edit `redact-lists.js` (`COMPANIES`, `PHRASES`, `NAMES`).
2. `node apply-redact.js` — re-cleans the built-in data into `data\baseline.redacted.json`.
3. `node build.js`

The page never contains these lists; it only holds one-way codes generated by `gen-redact.js`.

## Files

| File | What it is |
|---|---|
| `app.js` | Page logic for ticket data (filters, charts, "My charts", uploads, exports, drawer, rules) |
| `generic.js` | General-data mode: dashboard built from any spreadsheet's columns, plus "My charts" |
| `auth.js` | Sign-in screen, encryption of the built-in data and of browser storage |
| `charts.js` | "My charts" drawing (bar, donut, stacked, line, tables) and PNG download, for both modes |
| `auth.private.json` | Dashboard user ID and password (build only, private) |
| `body.html` | Page markup |
| `css_head.part`, `extra.css` | Styles (light and dark) |
| `redact-runtime.js` | Name, email and customer-number removal used in the page |
| `redact-lists.js` | Names to remove (build only, private) |
| `gen-redact.js` | Turns the lists into codes → `redact.gen.js` |
| `assemble.js` | Joins styles, markup and script → `template.html` |
| `build.js` | Adds data and rules, encrypts the data, writes the two output pages |
| `apply-redact.js` | Cleans `data\baseline.json` → `data\baseline.redacted.json` |
| `gen-sample-data.js` | Writes the fictitious Contoso Workplace demo tickets → `data\baseline.json` |
| `data\` | Built-in tickets: original and cleaned |

Generated files (`template.html`, `redact.gen.js`, `dist\`) are recreated on every build.
